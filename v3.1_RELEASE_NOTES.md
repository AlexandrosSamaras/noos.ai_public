# Noos.AI v3.1.0 Release Notes

Noos.AI v3.1.0 introduces the Inline Ghost Writer, AI Voice Cloning DNA Preview, Shareable Report Links, 1-Click License Auto-Activation, and a unified Google Sans design language across the extension and Web Studio.

## What's New in v3.1.0

### 1. Inline Ghost Writer (Gmail, LinkedIn, X, Google Docs & More)
* Focus any text box or `contenteditable` editor to reveal the floating **Noos.AI** Ghost Writer pill.
* Polish drafts, generate context-aware replies, or switch tone (**Executive**, **Friendly**, **Concise**, **Persuasive**) in 1 click with instant in-place text replacement.

### 2. AI Voice Cloning ("Train Your Voice") & Free DNA Preview
* Paste 3 writing samples in the Options page to analyze your vocabulary, sentence rhythm, and tone.
* Free Daily Pilot users can generate and preview their personal Voice DNA Profile; Noos.AI Pro users apply their active Voice Clone across all rewrites and replies automatically.

### 3. Custom Persona Manager (1 Free Persona + Unlimited Pro Cloud Sync)
* Free users can now create and save **1 Custom AI Persona** to customize analysis and writing output.
* Pro users unlock **Unlimited Custom Personas** with cloud synchronization across the extension and Web Studio.

### 4. 1-Click Shareable Report Links & Markdown Briefs
* Every result panel now includes a **Share Link** button that generates a public report URL on `noosai.co.uk/app/report.html` (with automatic Markdown Brief fallback) so you can share insights with teammates and clients immediately.

### 5. Frictionless 1-Click License Activation
* Upgrading to Noos.AI Pro now auto-detects and activates your license key directly from the post-checkout confirmation page—no manual copy-pasting required.

### 6. Unified Google Sans Typography & Clean UI
* Standardized typography across the popup, options page, in-page result panels, and Ghost Writer widget using **Google Sans** and **Roboto** with a clean, distraction-free, emoji-free interface.
